Custom Mobile Test Framework | Java + Appium + TestNG

🔍 Project Overview

A custom mobile automation framework built for both Android & iOS platforms. Designed with scalability, reusability, and CI/CD integration in mind.

🚀 Key Features

  • Java-based Appium framework with TestNG integration
  • Flexible device profiles (JSON-based config)
  • Support for hybrid, native apps
  • Robust reporting via ExtentReports/TestNG
  • Retry logic, logging, and test listeners

🛠 Tech Stack

  • Java
  • Appium
  • TestNG
  • Log4j
  • Maven
