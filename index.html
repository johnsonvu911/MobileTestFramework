Custom Web Automation Framework | Java + Selenium + TestNG

🔍 Project Overview

This is a custom-built, scalable Web Automation Framework designed for robust, maintainable testing across web platforms.

🚀 Key Features

  • Java + Selenium WebDriver + TestNG base architecture
  • Page Object Model with clear separation of concerns
  • Cross-browser execution support
  • Reusable actions and test utilities
  • Integrated test reports & logs

🛠 Tech Stack

  • Java
  • Selenium WebDriver
  • TestNG
  • Log4j
  • Maven
